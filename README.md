# Greens Delight Hub

我想要做一個銷售蔬食商品的網頁，其中一個商品就是紅毛苔，包括中藥口味。薑香口味。原味．並且有三種大包250克。中包150克。小包90克的重量，要讓顧客填資料
而且要製作一個包含能夠串接行銷數據的後台（Meta google），並且能夠串街Line通知的後台管理系統，先給示範資料再讓我後續逐步串接
